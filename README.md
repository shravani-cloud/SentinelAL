# SentinelAI 🛡️

### AI-Powered Cybersecurity Threat Intelligence Analyst

SentinelAI is a machine learning and Generative AI-powered cybersecurity project designed to detect suspicious network traffic, identify potential cyberattacks, and generate intelligent security explanations.

## 🎯 Project Objectives

- Detect malicious network traffic.
- Identify unusual network behaviour.
- Classify different cyberattack categories.
- Generate AI-powered threat explanations.
- Map detected behaviours to MITRE ATT&CK.
- Provide a cybersecurity monitoring dashboard.

## 🧠 Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Random Forest
- Isolation Forest
- Generative AI
- Sentence Transformers
- FAISS
- Streamlit
- SQLite

## 🏗️ Project Status

Currently under development.

## 📊 Dataset

UNSW-NB15 cybersecurity dataset.
